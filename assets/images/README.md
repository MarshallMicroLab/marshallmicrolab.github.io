# Site images

Optional images belong here:

- `mml-logo.png` — lab logo; uncomment `logo` in `_config.yml` after adding it.
- `social-preview.png` — default OpenGraph image; uncomment `social_image` in `_config.yml` after adding it.
- `people/` — portraits referenced by `photo` in people Markdown.
- `research/` — project images referenced by `image` in research Markdown.
- `software/` — logos and screenshots referenced by software Markdown.

Cards render designed fallbacks whenever an image path is blank, so no image is required.
